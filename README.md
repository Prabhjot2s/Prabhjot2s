### What I've built

I build with Claude Code as my pair programmer: I decide what to build, write the spec, review every change and test it on real data. It lets one analyst ship tools that would normally need a small team.

| Project | What it does | Built with |
|---|---|---|
| [**InsightDesk**](https://prabh-insightdesk.netlify.app) | Ask a spreadsheet a question in plain English and get the number, the chart and a written read. The AI only plans the query; the browser computes every figure, so nothing is made up, and a "show how this was calculated" panel proves it. | React, Recharts, SheetJS, Netlify Functions, Vitest |
| **Channel analytics tracker** | One tracker for six YouTube and Instagram channels. It pulls stats through the platform APIs, logs every change made to a video (hook, length, title, thumbnail) and scores which changes actually moved views and retention, so the next video starts from evidence. | Python, YouTube Data API, Instagram Graph API |
| **AI video pipelines** | Script-to-render pipelines: research, script, AI voice, image and video models running on my own GPU, code-built motion graphics, and automated critic reviews before anything renders. They power my [YouTube channel](https://www.youtube.com/@BarelyComplicated-m) and [client videos](https://frameshiftanimation.netlify.app). | ComfyUI, HyperFrames, ElevenLabs, Python |
| **ClipDesk** · *private* | A hand-off board for a two-person content team: finished reels are pushed from the editing PC, a teammate downloads and posts them from a phone, and both track every clip's status. It also schedules Instagram posts from the cloud, so they go out with the PC off. | Cloudflare Workers, R2, D1, Hono, React |
| **ConvertDesk** · *private* | A desktop app that replaces online file converters: images, HEIC, video, audio, PDF to Word, Markdown and GPU transcription, all offline, with a right-click menu in File Explorer. | Python, PySide6, PyMuPDF |
| **Telegram → Claude gateway** · *private* | Runs several Telegram bots from one process. Each bot has its own allowed users, working folder, memory and usage limits, with owner approval for expensive jobs. | Python, asyncio |
